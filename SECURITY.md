# Security Policy

## Purpose of this repository

This project is a **defensive honeypot / threat-intelligence lab**.

- Sample files under `data/downloaded/` are **safe mocks**, not live malware.
- Live Cowrie deployments must use isolated lab hosts and non-production ports (`2222` / `2223` by default).
- Do not point the honeypot at networks you do not own or have explicit permission to test.

## Reporting issues

If you find a documentation gap or a safety concern in the lab setup, open a GitHub Issue on this repository.
