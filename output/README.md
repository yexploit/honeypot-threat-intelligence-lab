# Output folder

Generated automatically by:

```bash
python -m honeypot_lab
```

| Path | Contents |
|------|----------|
| `iocs/` | IOC database (JSON + CSV) |
| `reports/` | Threat report, attacker behavior report, classifications, feed correlation, payload analysis, defensive recommendations |
| `timelines/` | Global + per-attacker attack timelines (Markdown + JSON) |

These files are committed so the repository is immediately readable on GitHub without running the pipeline first.
